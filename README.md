# Week 1 Database Assignment

## Topic: Online Shop

This repository contains the MySQL database assignment for an online shop.

The SQL solution is in [answer.sql](answer.sql). It creates the `online_shop` database, defines customers, products, orders, and order items, inserts sample data, and runs verification queries.

## Run the assignment

Open `answer.sql` in MySQL Workbench or run it from the MySQL terminal after connecting to your MySQL server.
